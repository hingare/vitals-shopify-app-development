# Built for Shopify: শর্ত আর আমাদের অবস্থা

Shopify-র [Built for Shopify শর্তগুলো](https://shopify.dev/docs/apps/launch/built-for-shopify/requirements)
অ্যাপের সাথে মেলানোর তালিকা (স্টেজ ৮)। ✅ মানে কোডে আছে, ⏳ মানে আসল দোকান বা লাইভ ডেটা লাগবে,
❌ মানে এখনো বানানো হয়নি।

## আবেদনের আগে যা লাগবে

| শর্ত                                                       | অবস্থা | মন্তব্য                                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------------------------------------------------- | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ৫০টা নেট ইনস্টল, ৫টা রিভিউ, ন্যূনতম রেটিং                  | ⏳     | পাবলিক লঞ্চের পরে                                                                                                                                                                                                                                                                                                                                                                            |
| Admin Web Vitals (p75): LCP ≤ 2.5s, CLS ≤ 0.1, INP ≤ 200ms | ⏳     | App Bridge নিজেই মাপে; বেটার পরে Partner Dashboard-এ দেখতে হবে                                                                                                                                                                                                                                                                                                                               |
| স্টোরফ্রন্ট Lighthouse ১০ পয়েন্টের বেশি না কমা            | ⏳     | CI-র `speed` ধাপ Shopify-র মতো মাপে (মোবাইল Lighthouse, হোম/প্রোডাক্ট/কালেকশন ১৭/৪০/৪৩%) একটা Dawn-এর মতো ভারী নকল দোকানে, সব ৫১টা টুল একসাথে চালু রেখে: স্কোর কমে ০.৪–১.৫ পয়েন্ট (লক্ষ্য ২, ৫-এর বেশি হলে CI লাল)। লোডার ৫KB-র নিচে, প্রতিটা টুল ১০KB-র নিচে, প্রতিটা টুলে CLS-ও CI-তে ([storefront-tests.md](storefront-tests.md)); আসল দোকানে একই মাপ `SPEED_BEFORE`/`SPEED_AFTER` দিয়ে |

## বেটার সময় যা দেখতে হবে

- Shopify মোবাইল অ্যাপে সেভ বার আর ডায়ালগ ঠিকমতো দেখা যায় কিনা।
- নতুন অফার বা নতুন ক্যাম্পেইন প্রথমবার সেভ হলে পাতা তার নিজের ঠিকানায় যায় আর সেভ বার বন্ধ হয় কিনা।
- Customers → Segments → কোনো সেগমেন্ট → "Use segment" তালিকায় "Send an email campaign" আসে, আর Create campaign চাপলে অ্যাপের ক্যাম্পেইন এডিটর খোলে সেগমেন্টটা বাছা অবস্থায় (লিংক `/app/marketing/campaigns/new?segment=…`)।
- জটিল সেগমেন্টে (যেমন অর্ডারের শর্ত) পাঠানো ঠিকমতো শেষ হয় কিনা: Shopify আগে তালিকা বানায়, তারপর ২৫০ জন করে আসে।
- কয়েকটা আলাদা থিমে (Dawn ছাড়াও) app embed বন্ধ আর চালু রেখে Lighthouse (মোবাইল): `SPEED_BEFORE`/`SPEED_AFTER` দিয়ে `pnpm --filter @app/widgets speed` ([storefront-tests.md](storefront-tests.md), "আসল দোকানে মাপা")।
